AWS Waste Finder

Find the AWS charges nobody is using.

Idle NAT gateways, forgotten volumes, Elastic IPs pointing at nothing. Waste Finder scans every region of an account with read-only access and puts a monthly price on each one.

Scan my account

Read-only. It can't see your data, and it can't change anything.

What it looks for

Idle NAT gateways
No traffic for 14 days. $32.85/month each before data charges.
Unattached EBS volumes
Disks still billed after their instance is gone, priced by type, size and IOPS.
Over-provisioned instances
Pulled from AWS Compute Optimizer, which prices the right size for you.
Idle load balancers
No registered targets, or no requests in 14 days.
Orphaned snapshots
Older than 90 days, source volume deleted, not used by an AMI or AWS Backup.
gp2 volumes
gp3 is about 20% cheaper. The math accounts for IOPS above the free baseline.
Log groups that never expire
Large log groups with no retention setting keep growing the bill.
Instances stopped for 30+ days
Stopped compute is free. Its disks are not.
Abandoned multipart uploads
Invisible in the S3 console, billed as storage.
Unused Elastic IPs
Every public IPv4 address costs $3.65/month.

Scan your own account

Three steps, about five minutes. You create a temporary read-only role, run the scan, then delete the role.

Live scanning isn't connected on this copy of the site. The sample scan above shows the full report.

  1. Create the read-only role

    This opens the AWS console with a CloudFormation stack ready to create. The role can list resources and read usage metrics. It can't read files, logs or databases, and it only works with the one-time ID below.

    Open AWS console

    One-time ID: . In the console, tick the IAM acknowledgement and choose Create stack. Wait for CREATE_COMPLETE.

  2. Run the scan

  3. Delete the role

    When you're done, delete the WasteFinderReadOnly stack in CloudFormation. Access ends the moment it's gone. Results here expire within a day.
